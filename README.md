# Aguri Heritage resources

Original Bengali journal volumes supporting [Aguri Heritage](https://aguri-heritage.pages.dev/), an English-language heritage project about the Aguri / Ugra Kshatriya community of West Bengal.

[Download the original journal PDFs](https://github.com/rn5678/aguri-heritage-resources/releases/tag/journals-v1).

- **Ugrakshatriya-Pratinidhi, Volume I** — 1298 Bangabda (1891–92), 175 scanned images.
- **Ugrakshatriya-Pratinidhi, Volume II** — 1299 Bangabda (1892–93), 167 scanned images.

The project owner supplied these historical scans. Original pagination and library marks are retained. Most scans contain two printed pages. The scans are historical source material; their views and classifications belong to their authors and period.

The website provides a [scanned-page reader](https://aguri-heritage.pages.dev/archives), selected English translations and an explicitly unreviewed Bengali OCR layer. The PDFs here are the original Bengali volumes, not full English translations.
