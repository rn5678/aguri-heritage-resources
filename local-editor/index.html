Editing tips

Choose “Add text block” to write a new paragraph beside the selected block, or use Add above / Add below on a block. Delete block removes a complete paragraph; Restore brings it back before saving. “Undo block change” reverses block additions or removals, while normal Undo also works for text edits. Required headings and captions stay in place, but their text can be edited. Use Jump to text to move around the page.
